🔵 A* 搜索算法
A-Star Search Algorithm — 最优启发式搜索
⚡ 核心原理
  • 在网格/图中寻找最短路径的启发式搜索算法
  • 结合实际代价（从起点）和预估代价（到终点）
  • 维护两个集合：Open List（待探索）和 Closed List（已探索）
  • 每次选择 f(n) 最小 的节点扩展，保证最优性
🧮 核心公式
f(n) = g(n) + h(n)

g(n) = 从起点到节点n的实际代价（已知）
h(n) = 从节点n到终点的启发估计（启发函数）
f(n) = 经过n的最优路径总代价估计

// 常用启发函数：欧氏距离、曼哈顿距离、对角距离
h(n) = √[(xₙ-x₉)² + (yₙ-y₉)²] // 欧氏距离

🟡 粒子群优化 (PSO)
Particle Swarm Optimization — 群体智能优化
⚡ 核心原理
  • 模拟鸟群/鱼群群体觅食行为的元启发式算法
  • 每个"粒子"代表解空间中的一个候选解
  • 粒子通过跟踪个体最优(pbest)和全局最优(gbest)更新
  • 适用于连续空间优化，如无人机三维路径规划
🧮 核心公式
// 速度更新公式（核心）
vᵢ(t+1) = w·vᵢ(t) + c₁r₁·(pbestᵢ - xᵢ) + c₂r₂·(gbest - xᵢ)

// 位置更新公式
xᵢ(t+1) = xᵢ(t) + vᵢ(t+1)

w = 惯性权重（控制探索/开发平衡）
c₁, c₂ = 学习因子（个体/社会认知系数）
r₁, r₂ = [0,1] 随机数
pbestᵢ = 粒子i的历史最优位置
gbest = 整个种群的历史最优位置

🟣 Q-Learning 强化学习
Model-Free RL — 无模型时序差分学习
⚡ 核心原理
  • 无模型(Model-Free)：不需要知道环境转移概率
  • 维护一张 Q-Table：状态-动作值函数 Q(s,a)
  • 通过试错探索学习最优策略（ε-贪心策略）
  • 利用 时序差分(TD) 更新：用下一步估计修正当前估计
  • 最终策略：每个状态选择 Q值最大的动作
🧮 核心公式
// Q值更新（Bellman方程的TD实现）
Q(s,a) ← Q(s,a) + α · [r + γ·maxQ(s',a') - Q(s,a)]

α = 学习率 (0~1)，控制新信息覆盖旧信息的程度
γ = 折扣因子 (0~1)，未来奖励的衰减系数
r = 执行动作a后获得的即时奖励
s' = 执行动作a后转移到的下一状态
maxQ(s',a') = 下一状态所有动作中的最大Q值

// ε-贪心策略（探索 vs 利用）
以 ε 概率随机选动作（探索），以 1-ε 概率选Q最大动作（利用）

📊 三种算法核心对比
Comparison of A*, PSO, and Q-Learning
维度 A* 搜索 PSO 粒子群 Q-Learning
算法类型 图搜索 / 启发式搜索 群体智能 / 元启发式 强化学习 / 时序差分
是否需要环境模型 需要（图/网格结构） 不需要（黑箱优化） 不需要（Model-Free）
解空间 离散（网格节点） 连续（实数向量） 离散（状态-动作对）
核心迭代对象 节点扩展（Open/Closed List） 粒子位置/速度更新 Q-Table值更新（TD）
最优性保证 ✅ 启发函数可采纳时保证最优 ❌ 不保证全局最优（可能局部最优） ✅ 充分探索后收敛到最优策略
适用场景 已知地图的静态最短路径 连续空间多目标优化 未知环境的序列决策
计算瓶颈 Open List排序（高维时指数爆炸） 适应度函数评估次数 状态空间维度（Q-Table大小）
对无人机的意义 静态地图全局路径规划 三维路径点优化（平滑+避障） 动态环境下的实时避障决策
🚁 在无人机路径规划中的应用方式
算法 典型应用 优势 局限
A* 已知地图的全局路径规划；栅格地图最短路径；作为基准对比 保证最优；逻辑清晰；实现简单 高维空间计算量大；无法处理动态障碍；路径不够平滑
PSO 三维路径点优化；多目标优化（长度+威胁+能耗）；与A*结合做后处理平滑 连续空间优化强；并行计算；易处理多目标 可能陷入局部最优；参数敏感；收敛速度不稳定
Q-Learning 动态环境下的实时避障；未知环境中的探索-利用决策；与A*结合的动态重规划 无需环境模型；自适应学习；可处理随机性 状态空间大时Q-Table爆炸；训练时间长；初期探索效率低

A* 算法伪代码

# 初始化 open_list = [start_node] # 优先队列，按f值排序 closed_list = [] # 已访问集合 g[start] = 0 f[start] = heuristic(start, goal) while open_list not empty: current = pop_min_f(open_list) # 取出f最小的节点 if current == goal: return reconstruct_path(current) # 回溯路径 closed_list.add(current) for neighbor in get_neighbors(current): if neighbor in closed_list: continue tentative_g = g[current] + cost(current, neighbor) if tentative_g < g[neighbor] or neighbor not in open_list: g[neighbor] = tentative_g f[neighbor] = g[neighbor] + heuristic(neighbor, goal) neighbor.parent = current if neighbor not in open_list: open_list.push(neighbor)

PSO 算法伪代码

# 初始化粒子群 for i = 1 to N: particle[i].position = random(bounds) particle[i].velocity = random(v_max) particle[i].pbest = particle[i].position particle[i].pbest_fitness = fitness(particle[i].position) gbest = argmax(pbest_fitness) # 迭代优化 for iter = 1 to max_iter: for i = 1 to N: # 速度更新（惯性 + 个体认知 + 社会认知） v[i] = w * v[i] + c1 * rand() * (pbest[i] - x[i]) + c2 * rand() * (gbest - x[i]) # 位置更新 x[i] = x[i] + v[i] x[i] = clip(x[i], bounds) # 边界约束 # 更新个体最优 if fitness(x[i]) < particle[i].pbest_fitness: particle[i].pbest = x[i] particle[i].pbest_fitness = fitness(x[i]) # 更新全局最优 if particle[i].pbest_fitness < gbest_fitness: gbest = particle[i].pbest w = w * 0.99 # 惯性权重衰减

Q-Learning 算法伪代码

# 初始化Q-Table（状态数 × 动作数） Q = zeros(num_states, num_actions) epsilon = 1.0 # 初始探索率 alpha = 0.1 # 学习率 gamma = 0.9 # 折扣因子 # 训练多个Episode for episode = 1 to max_episodes: state = env.reset() # 重置环境到初始状态 done = False while not done: # ε-贪心策略选择动作 if random() < epsilon: action = random_action() # 探索：随机选 else: action = argmax(Q[state, :]) # 利用：选Q最大 # 执行动作，观察转移 next_state, reward, done = env.step(action) # TD更新：朝目标值移动一步 target = reward + gamma * max(Q[next_state, :]) Q[state, action] += alpha * (target - Q[state, action]) state = next_state epsilon *= 0.995 # 逐渐降低探索率 # 最终策略：每个状态选Q值最大的动作 policy[s] = argmax(Q[s, :]) for all s
